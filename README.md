# IoT 실습 스타터 킷 사용법

이 압축파일 안의 폴더/파일들은 전부 **속이 비어있습니다.** 교재에 나온 코드를 그대로 복사해서 해당 파일에 붙여넣기만 하면 됩니다. 폴더나 파일을 새로 만들 필요가 없습니다.

> 폴더/파일 이름은 한글 깨짐을 방지하기 위해 전부 영문으로 만들었습니다.

## 폴더 구성

| 폴더 | 어디로 옮기나 | 어떤 교재 코드가 들어가나 |
|---|---|---|
| `week1-pico-local` | Pico의 `CIRCUITPY` 드라이브 **루트**로 복사 | 1주차 교재 실습 1~4, 종합 실습 |
| `week2-pico-wifi` | Pico의 `CIRCUITPY` 드라이브 **루트**로 복사 (덮어쓰기) | 2주차 교재 12~15번 항목 |
| `week2-nextjs-api` | `npx create-next-app` 으로 만든 프로젝트 폴더 **안에 병합** | 2주차 교재 6~9번 항목 |
| `week3-pico-websocket` | Pico의 `CIRCUITPY` 드라이브 **루트**로 복사 (덮어쓰기) | 3주차 교재 4번 항목 |
| `week3-nextjs-dashboard` | 2주차 Next.js 프로젝트 폴더 **안에 병합** | 3주차 교재 5번 항목 |
| `week4-nextjs-redesign` | 같은 Next.js 프로젝트 폴더 **안에 병합** (기존 파일 덮어쓰기) | 4주차 교재 4~6번 항목 |

## Pico 쪽 사용법 (1, 2, 3주차 `pico-` 폴더)

1. 폴더 안의 `.py`/`.toml` 파일들을 그대로 **CIRCUITPY 드라이브 루트**에 복사합니다.
2. VS Code에서 해당 파일을 열고, 교재에 있는 코드를 복사해서 붙여넣습니다.
3. `settings.toml`은 Wi-Fi 이름/비밀번호를 본인 값으로 수정하는 것도 잊지 마세요.
4. 매주 폴더를 그대로 덮어씌우면 되므로, 이전 주차 파일이 남아있어도 상관없습니다 (같은 이름의 `main.py`는 최신 주차 것으로 교체됨).

## Next.js 쪽 사용법 (2, 3, 4주차 `nextjs-` 폴더)

1. 2주차를 시작할 때 딱 한 번만 아래 명령으로 프로젝트를 새로 만듭니다.
   ```bash
   npx create-next-app@latest iot-week2-api --typescript --app --eslint --tailwind --src-dir --import-alias "@/*"
   ```
2. 이 스타터 킷의 `week2-nextjs-api` 폴더 안에 있는 `src`, `.env.local`을 방금 만든 `iot-week2-api` 프로젝트 폴더 안에 **그대로 덮어써서 합칩니다** (같은 이름의 폴더/파일은 병합, 새 파일은 추가).
3. 각 빈 파일을 열어 교재 코드를 붙여넣습니다.
4. 3주차, 4주차가 되면 그 주차의 `nextjs-` 폴더 안 파일들을 **같은 프로젝트 폴더에 다시 덮어써서** 합치고, 새로 채워지는 파일에 그 주차 코드를 붙여넣으면 됩니다.

## 주의할 점

- 폴더를 병합할 때 "덮어쓰기" 여부를 물으면 **덮어쓰기**를 선택하세요 (이전 주차 내용 위에 새 주차 내용이 쌓이는 방식입니다).
- `node_modules`, `package.json` 등 `create-next-app`이 만든 나머지 파일들은 이 스타터 킷에 없습니다 — 정상입니다. 그 파일들은 안 건드립니다.
- 파일을 다 채운 후에는 교재의 "실행 및 확인" 절차대로 진행하면 됩니다.
