# 11주차 · 바이브 코딩으로 우리 팀 화면 완성하기

노션 교재 **「11주차 · 바이브 코딩으로 우리 팀 화면 완성하기」** 의 배포 파일입니다.

학생들은 18세 미만이라 AI 에이전트형 도구(Claude Code, Codex, Antigravity 등)에 제약이 있어,
**학교 구글 계정의 제미나이 채팅**에 소스와 규칙 문서를 올리고 프롬프트로 요청하는 방식을 씁니다.

## 학생에게 나눠줄 파일

| 파일 | 용도 |
|---|---|
| `bundle-source.js` | **프로젝트 폴더에 넣고 실행** — 소스를 한 파일로 묶음 |
| `프로젝트-규칙.md` | **소스와 함께 제미나이에 업로드** — 컨텍스트 문서 |
| `프롬프트-모음-스마트팜.md` | **수업 중 예제 — 빈칸 없는 완성형.** 모든 팀이 같은 것을 만듭니다 |
| `프롬프트-모음.md` | 빈칸 서식 — 우리 팀 주제로 옮길 때 참고 |
| `../worksheets/바이브코딩_워크시트.html` | **다음 시간 — 우리 팀 주제용.** 브라우저로 열어 쓰는 입력 워크시트 |

## 수업은 두 번에 나눠 합니다

| 언제 | 무엇을 | 쓰는 파일 |
|---|---|---|
| **11주차 수업** | 모두 같이 **「교실 스마트팜」** 을 만들며 프롬프트 0~7 익히기 | `프롬프트-모음-스마트팜.md` |
| **그다음** | **우리 팀 주제**로 같은 일 하기 | `../worksheets/바이브코딩_워크시트.html` |

주제가 같아야 옆 사람과 비교하면서 배울 수 있습니다. 바이브 코딩 시간은
*무엇을 만들까*를 고민하는 시간이 아니라 **AI에게 제대로 부탁하는 법**을 익히는 시간입니다.

### 예제 — 교실 스마트팜

9주차 화면(센서 5개)에 **센서 1개와 액추에이터 1개**만 더합니다.

| 추가 | 부품 | 핀 | JSON 키 | 전원 |
|---|---|---|---|---|
| 센서 | 토양수분 (정전용량식 v1.2) | GP27 (ADC1) | `soil` | 3V3 (오른쪽 레일) |
| 액추에이터 | 스텝모터 28BYJ-48 + ULN2003 — 급수 밸브 | GP10 · GP11 · GP12 · GP13 (IN1~IN4) | `valve` | **외부 5V — 수업에서는 연결 안 함** |

> 🖥️ **스텝모터는 수업에서 실제로 연결하지 않습니다.** 스마트팜은 **프롬프트 연습용 예제**입니다.
> 밸브 코드는 받아서 붙여넣고, **가상 Pico 창에 `[WS] 수신 메시지` 와 `[WS] 명령 적용 완료` 가 찍히는 것까지**만 확인합니다.
> 비차단으로 돌리고 있는지는 **코드를 눈으로 읽어** 판단합니다 — 실물 모터가 없어도 찾아낼 수 있어야 합니다.
> **토양수분 센서는 그대로 실물로 붙입니다** (전원이 3V3 하나뿐이라 안전).
> 스텝모터 단독 시험 코드·배선표·주의사항은 `프롬프트-모음-스마트팜.md` 맨 뒤 **「부록」** 에 모아 두었습니다 —
> **작품에 스텝모터를 쓰기로 한 팀이 방과후에** 보는 내용입니다.

토양수분은 10주차 예시 코드(`../week10-transplant/main_week10_example.py`)와 **같은 핀·같은 키**를 씁니다.
액추에이터는 실습 키트(에듀이노)에 물펌프·릴레이가 없고 **스텝모터와 드라이버가 있어** 스텝모터로 갑니다.
라이브러리 없이 `digitalio` 네 개로 돌리고, **한 번에 다 돌리지 않고 루프마다 몇 스텝씩** 움직여야
WebSocket 이 멈추지 않습니다 — 이것이 11주차의 새 교육 포인트입니다.
실물이 없어도 배우는 내용이 줄지 않는 이유가 여기 있습니다: **고쳐야 할 것이 코드 안에 있기 때문**입니다.

수업 중에 쓰는 프롬프트는 **1 · 1-B · 2 · 2-B · 3 · 3-B** 여섯 번입니다.

| 가상 Pico 창에 치는 것 | 확인하는 프롬프트 |
|---|---|
| `add soil 0 100` | 1 (화면에 센서 카드가 생기는가) |
| `add soil 0 25` / `add soil 60 100` | 3 (밸브가 저절로 열리고 닫히는가) |
| `add soil 0 15` + `h` | 3-B (경고 두 개가 동시에 뜨는가) |
| `fail soil` | 3 (`null` 일 때 **아무것도 하지 않는가** — 9주차 6단계) |
| `x` | 4 (자동 재연결) |

### 워크시트 (우리 팀 주제용)

`worksheets/바이브코딩_워크시트.html` 를 **브라우저로 열기만** 하면 됩니다 (설치·서버 불필요).

- 주제와 하드웨어를 입력하면 **프롬프트 0~5가 우리 팀 부품 이름·핀·JSON 키로 자동으로 채워집니다**
- 입력은 브라우저에 자동 저장되고, `PROJECT-PROMPTS.md` 로 내려받을 수 있습니다
- 교재 4-1절의 **전압 확인 · `code.py` 단독 시험 · 비밀번호 확인**이 프롬프트 앞에 들어 있습니다

## 소스 묶기 사용법

```bash
node bundle-source.js              # 화면 코드만
node bundle-source.js D:\          # Pico(CIRCUITPY) 코드도 같이
```

`우리팀-소스.md` 가 만들어지고, **무엇이 들어갔고 무엇이 빠졌는지 화면에 출력**됩니다.

### 자동으로 빠지는 것

| 대상 | 이유 |
|---|---|
| `.env*` | DB 접속 정보 |
| `settings.toml` | **CIRCUITPY_WIFI_PASSWORD — 실습실 공유기 비밀번호** |
| `node_modules/`, `.next/`, `.git/` | 용량 (업로드 100MB 제한) |
| 이미지·바이너리 | 불필요 |

추가로, **코드 안에 직접 적어둔 비밀번호도 찾아서 경고**합니다.
(`const WIFI_PASSWORD = "..."` 같은 줄)
