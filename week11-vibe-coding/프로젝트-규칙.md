# 이 프로젝트의 규칙 (반드시 먼저 읽어 주세요)

당신은 고등학교 1학년 학생의 IoT 작품 제작을 돕고 있습니다.
아래 규칙을 **모두** 지켜서 코드를 작성해 주세요.

---

## 1. 이 시스템이 무엇인가

Raspberry Pi Pico 2 W가 센서값을 재서 **WebSocket으로** 브라우저에 보내고,
브라우저(Next.js 대시보드)가 액추에이터 제어 명령을 Pico로 보냅니다.

```
[Pico 2 W]                          [브라우저 - Next.js 대시보드]
 CircuitPython                        React + react-bootstrap
 WebSocket "서버"      <== WS ==>     WebSocket "클라이언트"
 (센서값 전송,                         (센서값 표시,
  제어 명령 수신)                       제어 명령 전송)
```

**Pico가 서버이고 브라우저가 클라이언트입니다.** (보통과 반대입니다)

## 3. 절대 하면 안 되는 것

### 3-1. Pico 코드는 CircuitPython입니다. MicroPython이 아닙니다.

가장 많이 나는 실수입니다. 아래 표의 **오른쪽만** 쓰세요.

| ❌ MicroPython (쓰면 안 됨) | ✅ CircuitPython (이것만) |
|---|---|
| `from machine import Pin, ADC, PWM` | `import board, digitalio, analogio, pwmio` |
| `Pin(15, Pin.OUT)` | `digitalio.DigitalInOut(board.GP15)` |
| `ADC(Pin(26))` | `analogio.AnalogIn(board.GP26)` |
| `PWM(Pin(17))` | `pwmio.PWMOut(board.GP17, frequency=1000)` |
| `import utime` / `utime.sleep()` | `import time` / `time.sleep()` |
| `import network` | `import wifi` |
| `import urequests` | `import adafruit_requests` |
| `pin.value(1)` (함수 호출) | `pin.value = True` (속성 대입) |

`machine`, `utime`, `network`, `ubinascii` 같은 모듈이 답변에 나오면 **잘못된 것입니다.**

### 3-2. CSS 프레임워크는 Bootstrap 하나만 씁니다

- ❌ **Tailwind CSS 클래스 금지** — `flex`, `grid-cols-3`, `bg-gray-800`, `p-4`, `text-xl` 등
- ❌ **MUI(Material UI) 금지** — `sx={{}}`, `<Box>`, `<Grid size={}>` 등
- ❌ **shadcn/ui 금지**
- ✅ Bootstrap 유틸리티만 — `d-flex`, `g-3`, `p-3`, `fs-5`, `text-body-secondary`, `mb-4`

Bootstrap과 Tailwind를 같이 쓰면 `.container` 등이 충돌해 화면이 깨집니다.

### 3-3. Bootstrap 5 문법을 쓰세요 (4버전 아님)

| ❌ 옛날 문법 | ✅ 지금 문법 |
|---|---|
| `<Badge variant="success">` | `<Badge bg="success">` |
| `ml-2`, `mr-2`, `pl-3` | `ms-2`, `me-2`, `ps-3` |
| `text-muted` | `text-body-secondary` |
| `<Form.Group controlId=>` | `<Form.Label htmlFor=>` + `<Form.Control id=>` |

### 3-4. `bootstrap.bundle.min.js` 를 import 하지 마세요

react-bootstrap과 충돌해 모달이 두 번 열립니다. **CSS만** import합니다.

### 3-5. 새 라이브러리를 추가하지 마세요

`npm install`이 필요한 답변은 하지 마세요. 이미 있는 것만으로 해결해 주세요.
(차트가 꼭 필요하면 먼저 물어봐 주세요.)

### 3-6. 파일 구조와 배열 구조를 바꾸지 마세요

`SENSORS` / `SWITCHES` / `ALERTS` 배열과 `.map()` 구조는 수업에서 배운 것입니다.
**더 좋은 구조를 제안하지 말고 이 구조를 유지**해 주세요.

## 4. 반드시 지켜야 하는 것

- 화면 코드 파일 맨 윗줄에 **`"use client";`** 가 있어야 합니다.
- 센서값이 없을 수 있습니다. 타입은 **`number | null`** 이고, 없으면 화면에 `--`를 보여줍니다.
- Pico 쪽도 읽기에 실패하면 **`None`을 돌려줍니다.** 가짜 값을 지어내지 마세요.
- `ProgressBar`의 `now`는 **0~100 백분율**입니다. 센서 원본값을 그대로 넣지 마세요.
- 자동 제어에서 **센서값이 `null`이면 아무것도 하지 않습니다.** (`?? 0`으로 0 처리하면 안 됩니다)

## 5. 통신 규약 (JSON 키)

**Pico → 브라우저** (1초마다)

```json
{ "temperature": 24.0, "humidity": 55, "light_percent": 62.3,
  "cpu_temp": 38.9, "discomfort": 71.5 }
```

**브라우저 → Pico** (조작할 때마다)

```json
{ "servo_angle": 90, "led_r": 255, "led_g": 0, "led_b": 0 }
```

- 화면의 `SENSORS` 배열 `key`와 Pico가 보내는 JSON 키는 **글자 하나까지 같아야** 합니다.
- Pico는 `command.get("키", 0)` 으로 받아서, 키가 빠져도 나머지가 동작합니다.
- 켜짐은 `255`, 꺼짐은 `0`으로 보냅니다.

## 7. 배선 안전 — 센서를 추가할 때 반드시 같이 알려주세요

Pico의 GPIO는 **3.3V까지만** 감당합니다. 5V 신호가 들어오면 핀이 망가집니다.

**센서를 추가하는 코드를 줄 때는, 코드보다 먼저 아래 세 가지를 알려 주세요.**

1. 이 센서의 **전원이 3.3V인가 5V인가**
2. **센서가 Pico로 내보내는 신호(출력)가 5V인가** — 5V라면 **분압 저항이나 레벨 시프터가 필요하다고 반드시 경고**해 주세요
3. 전원을 **3V3(OUT) 36번**에서 받을지 **VBUS 40번(5V)** 에서 받을지

자주 쓰는 센서의 기준:

| 센서 | 전원 | Pico로 나가는 신호 | 조치 |
|---|---|---|---|
| 토양수분(정전용량식 v1.2) | 3.3~5.5V | 전원과 같은 범위 | 3V3에 연결하면 안전 |
| **HC-SR04 초음파** | 5V | **ECHO가 5V** | **분압(1kΩ+2kΩ) 필수** 또는 HC-SR04**P** 사용 |
| HC-SR501 PIR | 5V (VBUS) | OUT은 3.3V | 직결 가능 |
| PMS7003 미세먼지 | **5V (VBUS)** | TX는 3.3V | 데이터선 직결, 전원만 VBUS |
| 릴레이 모듈 | 5V (VBUS) | 입력만 받음 | 안전. 단 모터·펌프는 별도 전원 |

또한:

- **3V3(OUT)은 다 합쳐서 약 300mA까지**입니다. 서보·모터·펌프를 여기서 먹이면 Pico가 꺼졌다 켜집니다.
- **모든 장치의 GND를 Pico의 GND와 이어야** 합니다. 가장 자주 빠뜨립니다.
- **릴레이 모듈은 대부분 LOW일 때 켜집니다**(active-low). 코드를 줄 때 이 점을 알려주고, 켜짐/꺼짐이 반대면 어디를 바꾸면 되는지도 같이 적어 주세요.
- 릴레이는 **시작할 때 꺼진 상태로 초기화**하는 줄을 꼭 넣어 주세요. 없으면 전원을 넣자마자 펌프가 돕니다.

## 8. 센서를 추가할 때의 순서 — 이 순서로 안내해 주세요

학생이 한꺼번에 다 하려다 실패하지 않도록, **한 번에 하나씩** 진행하게 해 주세요.

1. 핀 정하기 (6번 항목의 남은 핀에서)
2. 전원·전압 확인 (7번 항목)
3. 배선 — **USB를 뽑은 상태에서**
4. **`code.py` 로 그 센서 하나만 읽어 시리얼에 출력** ← 여기서 숫자가 나와야 다음으로
5. 값 다듬기 (단위·범위, 실패하면 `None`)
6. `main.py` 의 payload 에 키 추가
7. 화면의 `SENSORS` 배열에 추가

> **4번을 건너뛰지 않게 해 주세요.** 대시보드에 바로 붙이면, 값이 안 나올 때 센서·배선·Pico 코드·화면 코드·키 이름 다섯 군데를 동시에 의심해야 합니다.
> CircuitPython은 `code.py` 가 있으면 `main.py` 대신 그것을 실행합니다. 그래서 **잘 돌던 `main.py` 를 건드리지 않고** 센서만 시험할 수 있습니다. 시험이 끝나면 `code.py` 를 지우거나 `code.py.bak` 으로 이름을 바꾸면 됩니다.

아날로그 센서 시험용 최소 코드의 모양:

```python
# code.py — 센서 하나만 시험
import time
import board
import analogio

sensor = analogio.AnalogIn(board.GP27)

while True:
    print("raw:", sensor.value)
    time.sleep(0.5)
```
