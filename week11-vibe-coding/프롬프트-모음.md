# 붙여넣기 전 검수 — 5분이면 됩니다

받은 코드를 **바로 붙여넣지 마세요.** 아래를 눈으로 훑습니다.

## 공통

- [ ] 코드의 **마지막 줄이 `}` 또는 `)` 로 제대로 끝나는가** (중간에 잘리지 않았는가)
- [ ] 파일 맨 위에 **경로 주석**이 있고, 내가 고치려는 파일과 같은가
- [ ] `npm install` 이나 `pip install` 을 하라는 말이 없는가

## 화면 코드 (`page.tsx`)

- [ ] 첫 줄이 **`"use client";`** 인가
- [ ] **Tailwind 클래스가 없는가** — `flex`, `grid-cols-`, `bg-gray-`, `text-xl`, `p-4` 등
      (Bootstrap은 `d-flex`, `g-3`, `text-body-secondary` 처럼 생겼습니다)
- [ ] `<Badge variant=` 가 아니라 **`<Badge bg=`** 인가
- [ ] `SENSORS` / `SWITCHES` / `ALERTS` **배열 구조가 그대로**인가

## Pico 코드 (`main.py`)

- [ ] **`machine`, `utime`, `network`** 가 없는가 → 있으면 MicroPython. 프롬프트 7로 다시 요청
- [ ] `import board`, `digitalio`, `analogio`, `pwmio` 를 쓰는가
- [ ] `pin.value = True` 형태인가 (`pin.value(1)` 이면 MicroPython)
- [ ] 읽기 실패 시 **`None`** 을 돌려주는가

## 붙여넣은 뒤

- [ ] **딱 한 가지만 확인** — 이번에 요청한 것이 되는가
- [ ] 안 되면 **바로 되돌릴 수 있는가** (고치기 전 파일을 복사해 뒀는가)

> 🎯 **고치기 전에 파일을 복사해 두세요.** `page.tsx` → `page.tsx.bak` 으로 이름만 바꿔 한 벌 두면,
> 잘못됐을 때 1초 만에 돌아갈 수 있습니다. `.bak` 은 Next.js가 무시합니다.
