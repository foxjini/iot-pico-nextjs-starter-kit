## 오늘 만들 것 — 교실 스마트팜

화분의 흙이 마르면 **물을 주고**, 어두우면 **생장등을 켜고**, 더우면 **환기창을 엽니다.**
9주차에서 만든 화면(센서 5개)에 **센서 1개와 액추에이터 1개**를 더합니다.

```
            [ 교실 스마트팜 ]

  흙이 마름  → 물펌프 ON      (토양수분 < 30%)
  어두움     → 생장등 ON      (조도 < 40%)
  더움       → 환기창 열기    (온도 > 28도)
```

### 하드웨어 — 오늘 추가하는 것은 두 개뿐입니다

| 구분 | 부품 | 핀 | JSON 키 | 전원 | 상태 |
|---|---|---|---|---|---|
| 센서 | DHT11 온습도 | GP16 | `temperature` · `humidity` | 3V3 | 9주차에서 이미 |
| 센서 | CdS 조도 | GP26 (ADC0) | `light_percent` | 3V3 | 9주차에서 이미 |
| 센서 | 칩 내장 온도 | — | `cpu_temp` | — | 9주차에서 이미 |
| 센서 | 불쾌지수 (계산) | — | `discomfort` | — | 9주차에서 이미 |
| **센서** | **토양수분 (정전용량식 v1.2)** | **GP27 (ADC1)** | **`soil`** | **3V3** | **★ 오늘 추가** |
| 액추에이터 | RGB LED — 생장등 | GP17 · GP18 · GP19 | `led_r` · `led_g` · `led_b` | 3V3 | 9주차에서 이미 |
| 액추에이터 | SG90 서보 — 환기창 | GP15 | `servo_angle` | **외부 5V** | 9주차에서 이미 |
| **액추에이터** | **릴레이 모듈 — 물펌프** | **GP20** | **`pump`** | **외부 5V** | **★ 오늘 추가** |

> ⚠️ **GP23 · GP24 · GP25 · GP29 는 쓰지 않습니다** (무선 칩 전용).
> 남은 아날로그는 GP27 · GP28 둘뿐이고, 그중 **GP27을 토양수분에 씁니다.**

### 부품이 없으면 — 가상 Pico로 그대로 진행합니다

토양수분 센서나 릴레이가 아직 없어도 **프롬프트 0 · 1 · 3 · 4 · 5 · 6 · 7 은 똑같이** 할 수 있습니다.

## 시작하기 전에 — 두 가지

### ① 소스 묶기 (비밀번호가 안 올라가는지 확인)

```bash
node bundle-source.js
```

실행 결과 화면에서 **이 줄을 눈으로 확인**하세요.

```
🔒 비밀번호가 들어있어 뺀 파일:
   .env.local
   CIRCUITPY/settings.toml

✅ 비밀번호처럼 보이는 줄은 없습니다.
```

마지막 줄이 `⚠️ 비밀번호처럼 보이는 줄이 남아 있습니다` 로 나오면 **그 줄을 고치기 전까지 올리지 마세요.**

### ② 토양수분 센서를 혼자 먼저 시험 (실물이 있는 팀만)

**대시보드에 바로 붙이지 마세요.** `CIRCUITPY/code.py` 로 저장하고 센서 하나만 봅니다.

```python
# code.py — 토양수분 센서만 시험
import time
import board
import analogio

soil = analogio.AnalogIn(board.GP27)

while True:
    print("raw:", soil.value)
    time.sleep(0.5)
```

| 확인할 것 | 적어 둘 곳 |
|---|---|
| **공기 중**(마른 상태)의 raw 값 | `SOIL_DRY` = ______ (보통 45000~50000) |
| **물에 담갔을 때**의 raw 값 | `SOIL_WET` = ______ (보통 18000~22000) |

> ⚠️ **흰 선까지만 담그세요.** 기판이 물에 닿으면 센서가 망가집니다.
> ⚠️ 시험이 끝나면 **`code.py` 를 지우거나 `code.py.bak` 으로 바꾸세요.**
> 안 지우면 `main.py` 가 실행되지 않아 "대시보드가 연결조차 안 된다"고 한참 헤매게 됩니다. **가장 흔한 실수입니다.**

### ③ 배선 — USB를 뽑고 하세요

| 부품 | 전원 | Pico로 나가는 신호 | 조치 |
|---|---|---|---|
| 토양수분 (정전용량식 v1.2) | **3V3** (오른쪽 빨강 레일) | 전원과 같은 범위 | 3V3에 연결하면 안전 |
| 릴레이 모듈 | **외부 5V** (왼쪽 빨강 레일) | 신호를 받기만 함 | 안전. 단 **펌프는 또 다른 전원** |

- **릴레이를 3V3에서 먹이지 마세요.** 3V3(OUT)은 다 합쳐 약 300mA입니다. Pico가 꺼졌다 켜집니다.
- **왼쪽 파랑 레일과 오른쪽 파랑 레일이 점퍼로 이어져 있어야** 합니다. 가장 자주 빠뜨리는 선입니다.
- **릴레이는 대부분 LOW일 때 켜집니다**(active-low). 프롬프트 2-B에 이 말이 들어 있습니다.

# 프롬프트 7 · AI가 규칙을 어겼을 때

```
방금 주신 코드는 규칙에 어긋납니다.

[무엇이 문제인지]

프로젝트-규칙.md 를 다시 확인하고, 규칙에 맞게 고쳐서

```

**스마트팜을 만들면서 실제로 자주 걸리는 것 — 그대로 복사해 쓰세요**

| AI가 준 것 | 「무엇이 문제인지」 에 쓸 말 |
|---|---|
| `from machine import Pin` | `Pico 코드에 machine 모듈이 들어 있습니다. 우리는 CircuitPython을 씁니다.` |
| `className="flex gap-4 bg-gray-800"` | `className 에 Tailwind 클래스가 들어 있습니다. 우리는 Bootstrap만 씁니다.` |
| `{"pump": true}` | `펌프 명령을 true/false 로 보냈습니다. 규칙 문서 5번대로 켜짐 255, 꺼짐 0 으로 보내 주세요.` |
| `code.py 를 고치세요` | `code.py 는 센서 단독 시험용입니다. 실제로 도는 것은 main.py 입니다.` |
| `SENSORS 배열 대신 이렇게 바꾸면...` | `수업에서 배운 배열 구조를 유지해 주세요. 더 좋은 구조를 제안하지 마세요.` |
| `npm install react-icons` | `새 라이브러리를 추가하지 마세요. 이미 있는 것만으로 해결해 주세요.` |

> 💡 **AI는 대화가 길어지면 처음에 준 규칙을 잊어버립니다.** 고장이 아니라 원래 그렇습니다.
> 너무 자주 어기면 **새 대화를 시작**하고 파일 두 개를 다시 올리세요. 이게 제일 빠릅니다.
