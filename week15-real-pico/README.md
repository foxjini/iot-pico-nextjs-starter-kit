# 15주차 · 가상 Pico 를 진짜 Pico 로

노션 교재 **「15주차 · 가상 Pico 를 진짜 Pico 로」** 의 배포 파일입니다.

학생들은 18세 미만이라 AI 에이전트형 도구에 제약이 있어, **학교 구글 계정의 제미나이 채팅**에
소스와 규칙 문서를 올리고 프롬프트로 요청하는 **컨텍스트 엔지니어링** 방식을 씁니다.
11 · 14주차와 같은 방법이고, **대상만 Pico 코드로** 바뀝니다.

---

## 🚩 언제 하는가 — 팀마다 다릅니다

이번 운영의 수업은 **1 · 2 · 3 · 8 · 9 · 11 · 14주차** 일곱 번이고, 15주차는 그 뒤에
붙이는 차시가 아니라 **작품 제작 시간에 쓰는 자료**입니다. 다만 **순서가 중요합니다.**

| 우리 팀은 | 언제 |
|---|---|
| **가상 Pico 로만 개발해 왔다** (실물로 한 번도 안 돌려 봄) | 🚨 **14주차 무인 리허설 전에 반드시** |
| 실물 Pico 로 이미 센서가 다 들어온다 | 14주차 뒤에 해도 됩니다 (팀 센서 추가분만) |

> **14주차 무인 리허설의 두 번째 항목이 「가상 Pico 창에 `x`」 입니다.**
> 전시장에는 가상 Pico 가 없습니다. **실물로 옮기지 않으면 리허설을 통과해도 전시가 안 됩니다.**

---

## 오늘 하는 일은 한 문장입니다

> 화면은 **가상 Pico 가 보내던 JSON** 에 맞춰 만들어졌습니다.
> **진짜 Pico 가 똑같은 JSON 을 보내게** 하면 **화면은 한 글자도 안 고쳐도 됩니다.**

| 파일 | 용도 |
|---|---|
| `프롬프트-모음-실물Pico.md` | **이번 시간에 쓰는 것.** 프롬프트 0 → 1 → 2 → 3 → 4 |
| `../week11-vibe-coding/프로젝트-규칙.md` | **소스와 함께 제미나이에 업로드** — **§11 이 오늘 핵심** |
| `../mock-pico/mock_pi_11.py` | **같이 업로드** — 무엇을 보내야 하는지의 **정답지** |

> ⚠️ **`page_...` 가 아니라 `main_week15_reference.py` 는 학생에게 주지 않습니다.** 선생님용입니다.

## 🚨 올리면 안 되는 파일

| 파일 | 들어있는 것 |
|---|---|
| **`CIRCUITPY/settings.toml`** | **실습실 공유기 비밀번호** |
| `.env.local` | 2주차 MySQL 접속 정보 |

`main.py` 는 `os.getenv("CIRCUITPY_WIFI_SSID")` 로 읽으므로 **코드 안에 비밀번호가 없습니다.**
그래서 `main.py` 는 올려도 됩니다. **`settings.toml` 만 빼면 됩니다.**

## 오늘의 교육 포인트 — **가져올 것과 가져오면 안 되는 것**

학생이 가상 Pico 파일을 올리면, AI 는 **그 파일의 코드 구조까지 Pico 로 옮기려** 합니다.
**그것이 오늘의 가장 큰 함정입니다.** 두 파일은 **같은 언어가 아닙니다.**

| | 가상 Pico (`mock_pi_11.py`) | 진짜 Pico (`main.py`) |
|---|---|---|
| 언어 | **CPython** (PC 용 파이썬) | **CircuitPython** |
| WebSocket | `socket` 으로 **직접 구현** (핸드셰이크·프레임까지) | **`adafruit_httpserver`** 가 해 줌 |
| 동시 처리 | `threading` | **`asyncio`** (`create_task` · `gather`) |
| 센서 값 | `random` · `math.sin()` 으로 **지어냄** | **`analogio` · `digitalio`** 로 실제 핀에서 |
| 기다리기 | `time.sleep(1)` | **`await async_sleep(1)`** |
| 콘솔 명령 | `x` · `add` · `fail` | **없음** — 실물에는 그런 것이 없습니다 |

> ✅ **가져올 것은 하나뿐입니다 — 「무엇을 보내는가」.**
> `build_payload()` 의 **JSON 키 목록**과 `apply_command()` 가 **받는 키**.
> 통신 구조는 학생의 `main.py` 에 있는 것을 **그대로 둡니다.**

이 내용을 `프로젝트-규칙.md` **§11** 에 넣어 두었습니다. 규칙 문서를 같이 올리면
AI 가 먼저 읽고 알아서 피합니다.

---

## 핵심 — 3주차 `main.py` 는 키를 **두 개 빠뜨리고** 있습니다

<table>

| JSON 키 | 가상 Pico | 3주차 `main.py` | 진짜 Pico 에서 만드는 법 |
|---|:---:|:---:|---|
| `temperature` | ✅ | ✅ | `adafruit_dht.DHT11` (**2초 이상 간격**) |
| `humidity` | ✅ | ✅ | 〃 |
| `light_percent` | ✅ | ✅ | `analogio.AnalogIn(board.GP26)` |
| **`cpu_temp`** | ✅ | ❌ **없음** | **`microcontroller.cpu.temperature`** — 부품 없이 읽힙니다 |
| **`discomfort`** | ✅ | ❌ **없음** | **`0.81*t + 0.01*h*(0.99*t - 14.3) + 46.3`** |
| 팀 센서 (`soil` 등) | 콘솔 `add` | ❌ 없음 | 실제 핀에서 읽기 |

</table>

**이 두 키가 빠진 채로 전시에 나가면** 화면의 「칩 온도」와 「불쾌지수」 카드에
**「데이터 없음」이 그대로 남습니다.** 프롬프트 0 이 그것을 찾아내게 하는 질문입니다.

> 💡 **`cpu_temp` 가 가장 먼저 성공합니다.** 칩 안에 들어 있는 온도계라 **배선을 하나도
> 안 해도** 값이 나옵니다. 실물 Pico 로 넘어간 첫 성공 경험으로 좋습니다.

## 프롬프트 순서

| | 하는 일 | 확인 |
|---|---|---|
| **0** | 무엇이 다른지 **표로** 받기 (아직 고치지 않음) | AI 가 `cpu_temp` · `discomfort` 를 찾아내는가 |
| **1** | 빠진 공통 키 채우기 | 그 두 카드에 **값이 들어오는가** |
| **2** | 우리 팀 센서를 **진짜로** 읽기 | 손으로 건드리면 **값이 움직이는가** |
| **3** | 우리 팀 액추에이터 움직이기 | 화면 버튼 → **실물이 움직이는가** |
| **4** | 센서 하나가 죽어도 안 멈추게 | 신호선을 뽑아도 **나머지가 들어오는가** |
| 마무리 | **가상 Pico 를 끄고** 30분 | **Traceback 0건** |

## 라이브러리 — 세 개가 다 있어야 합니다

| 넣을 것 | 모양 | 빠뜨리면 |
|---|---|---|
| `adafruit_httpserver` | **폴더** | `no module named 'adafruit_httpserver'` |
| `asyncio` | **폴더** | **CircuitPython 내장이 아닙니다** |
| `adafruit_ticks.mpy` | 파일 | `no module named 'adafruit_ticks'` ← **가장 많이 빠뜨립니다** |

`circup install asyncio` 를 쓰면 `adafruit_ticks` 까지 같이 깔립니다.

## 검증 결과 (2026-10-11)

모범답안 `main_week15_reference.py` 를 기계적으로 검사했습니다.
**실물 Pico 가 이 컨테이너에 없으므로 배선·동작은 미검증입니다** — 문법과 규칙만 확인했습니다.

| 확인 | 결과 |
|---|---|
| 파이썬 문법 (`py_compile`) | ✅ 통과 |
| **금지 모듈** (`machine` · `utime` · `network` · `socket` · `threading` · `random`) | ✅ **0건** |
| MicroPython 식 `pin.value(1)` 호출 | ✅ **0건** |
| 블로킹 `time.sleep()` | ✅ **0건** (`await async_sleep` 만) |
| 가상 Pico 공통 키 5개 | ✅ **전부 있음** |
| 팀 센서 예시 (`soil`) | ✅ 있음 |
| `discomfort` 식이 `mock_pi_11.py` 와 같은가 | ✅ 글자 단위 일치 |
| 비밀번호를 코드에 직접 썼는가 | ✅ 없음 (`os.getenv`) |

> ⚠️ **실물 검증은 선생님이 수업 전에 한 번 돌려 주세요.** 특히
> `microcontroller.cpu.temperature` 는 보드와 펌웨어 버전에 따라 값의 범위가 다릅니다
> (대체로 30~50℃). 화면의 `cpu_temp` 카드 `max` 값이 그 범위에 맞는지 같이 봐 주세요.

## 선생님용 메모

- **프롬프트 0 의 답이 오늘의 할 일 목록입니다.** AI 가 `cpu_temp` · `discomfort` 를
  스스로 찾아내면 제대로 읽은 것입니다. 못 찾으면 규칙 문서 §11 을 올렸는지 확인하세요.
- **AI 가 `socket` · `threading` 을 쓰겠다고 하면 멈추게 하세요.** 가상 Pico 를 베끼려는
  것입니다. 이것을 **학생이 알아채는 것**이 오늘 배우는 것입니다 — 프롬프트 5 로 되돌립니다.
- **`code.py` 를 안 지운 팀이 반드시 나옵니다.** 코드가 다 맞는데 연결조차 안 되면
  이것부터 보세요.
- **Pico 가 자꾸 재부팅되면 전원입니다.** 모터·펌프를 `3V3`(약 300mA)에서 먹이고 있는 것입니다.
- **IP 는 켤 때마다 바뀝니다.** 전시 당일 아침에 다시 확인하라고 일러 주세요
  (14주차 당일 점검표 2번 항목).
