
# 붙여넣기 전 검수 — 5분이면 됩니다

받은 코드를 **바로 붙여넣지 마세요.** 아래를 눈으로 훑습니다.

## 공통

- [ ] 코드의 **마지막 줄이 `}` 로 제대로 끝나는가** (중간에 잘리지 않았는가)
- [ ] 첫 줄이 **`"use client";`** 인가
- [ ] `npm install` 을 하라는 말이 **없는가** (`lucide-react` 는 이미 있습니다)
- [ ] **통신 코드가 그대로인가** — `openSocket` · `scheduleRetry` · `sendCommand` · 자동 제어 `useEffect`
- [ ] `SENSORS` / `SWITCHES` / `ALERTS` **배열 구조가 그대로**인가 (필드가 는 것은 괜찮습니다)

## Tailwind

- [ ] 색을 **토큰 이름**으로 썼는가 — `text-ok` ✅ / `text-green-500` ❌ / `text-[#4fa88f]` ❌
- [ ] 임의값 대신 **스케일**을 썼는가 — `p-3` ✅ / `p-[13px]` ❌
- [ ] 반응형이 **좁은 쪽부터**인가 — `grid-cols-1 sm:grid-cols-2` ✅
- [ ] `tailwind.config.js` 를 만들라고 하지 **않았는가** (v4 에는 없습니다)

## 오늘 세 가지

- [ ] **아이콘 옆에 글자가 남아 있는가** (아이콘만 있는 곳이 없는가)
- [ ] 장식 아이콘에 `aria-hidden` 이 붙었는가
- [ ] `focus:` 가 아니라 **`focus-visible:`** 인가
- [ ] `outline-none` 을 썼다면 **대신할 표시**가 반드시 있는가
- [ ] 390px 에서 **가로 스크롤이 없는가**

## 붙여넣은 뒤
