## 미션 1 · 전시 모드

```
11월 20일 전시회에 이 화면을 내놓습니다.
몇 시간 동안 사람 없이 켜 둘 예정인데, 지금은 노트북 화면이 저절로 꺼집니다.

"전시 모드" 버튼을 만들어 주세요.

- 켜면 화면이 꺼지지 않게 해 주세요 (Screen Wake Lock)
- 켜면 전체화면으로 바꿔 주세요
- 전시 모드에서는 IP 입력칸과 「장치 연결 / 연결 끊기」 버튼을 숨겨 주세요
  (관람객이 눌러서 꺼 버리면 안 됩니다)

★ 우리 팀 액추에이터 버튼은 관람객이 만지게 둘지 말지 제가 정합니다.
  - 관람객이 만져도 되는 것 (LED · 부저처럼 되돌아오는 것)
    → 전시 모드에서도 그대로 두세요. 관람객이 해 볼 거리입니다.
  - 관람객이 만지면 안 되는 것 (펌프 · 모터 · 히터처럼 물 · 열 · 움직임이 있는 것)
    → 전시 모드에서는 숨기거나, 켜면 몇 초 뒤에 저절로 꺼지게 해 주세요.
      무인 전시라 관람객이 켜 놓고 그냥 가 버립니다.
  제 액추에이터는 [            ] 이고, [그대로 둡니다 / 숨깁니다 / 몇 초 뒤 꺼지게 합니다].

★ Wake Lock 은 다른 탭에 갔다 오면 저절로 풀립니다.
  visibilitychange 로 화면이 다시 보일 때 한 번 더 걸어 주세요.

★ 전체화면을 빠져나갔을 때 전시 모드도 같이 꺼지게 해 주세요.
  ESC 를 누르면 전체화면만 풀리는데, 그러면 조작 버튼이 숨겨진 채로 남아서
  되돌릴 방법이 없어집니다. fullscreenchange 를 보고 처리해 주세요.

★ Wake Lock 을 지원하지 않는 브라우저에서도 오류가 나면 안 됩니다.
  try/catch 로 감싸 주세요.

대시보드 page.tsx 전체 완성본으로 주세요.
```

**확인**

| 해 보는 것 | 어떻게 되어야 하나 |
|---|---|
| 전시 모드를 켠다 | 전체화면이 되고 **조작 버튼이 사라진다** |
| **5분 동안 손대지 않는다** | 화면이 **안 꺼진다** |
| 다른 탭에 갔다 돌아온다 | 여전히 **안 꺼진다** |
| **ESC 를 누른다** | 전체화면이 풀리고 **조작 버튼이 다시 나온다** |

> 🚨 **마지막 줄이 오늘 가장 중요합니다.** 이게 없으면 전시 중에 누가 ESC 를 눌렀을 때
> **버튼이 숨겨진 채로 남아 아무것도 못 하게 됩니다.** 새로고침밖에 방법이 없습니다.

> 🚨 **전시 모드는 액추에이터 버튼을 막아 주지 않습니다 — 실제로 확인했습니다.**
> 전시 모드를 켜면 IP 칸과 연결 버튼은 숨지만, **11주차에 만든 액추에이터 버튼은
> 그대로 보이고 그대로 눌립니다.** 가상 Pico 로 재어 보니 관람객이 누른 명령이
> **Pico 까지 가서 적용됩니다** (`우리 팀 액추에이터 pump: 255 (켜짐)`).
> **펌프라면 관람객이 켜 놓고 그냥 갑니다.** 무인 전시 몇 시간이면 화분이 물에 잠깁니다.
>
> 다만 **숨기는 것이 늘 정답은 아닙니다.** 미션 3 은 「관람객이 직접 해 볼 수 있는 것
> 한 가지」를 요구합니다. **LED 처럼 안전한 것은 남겨 두는 것이 낫습니다** —
> 눌러 보고 반응을 확인하는 것이 전시의 핵심입니다. **위험한 것만 가리세요.**

## 미션 2 · 멀리서도 보이게

관람객은 **1m 쯤 떨어져서** 봅니다. 지금 글자 크기는 노트북 앞에 앉아 보는 크기입니다.

```
전시 모드일 때만 화면을 "멀리서 보는 크기" 로 바꿔 주세요.

- 센서 값 숫자를 훨씬 크게 (전시 모드가 아닐 때는 지금 크기 그대로)
- 제목과 설명처럼 관람객이 안 읽는 것은 전시 모드에서 숨기거나 작게
- 상태(정상 / 주의 / 위험)를 색만으로 알리지 마세요.
  색 + 아이콘 + 글자 세 가지가 같이 바뀌어야 합니다.

★ 크기는 조건부 className 으로 바꿔 주세요. 새 CSS 파일을 만들지 마세요.
★ const UI 객체를 쓰고 있으니 거기에 항목을 더해도 좋습니다.

대시보드 page.tsx 전체 완성본으로 주세요.
```

**확인**: 전시 모드를 켜고 **노트북에서 한 발짝 물러나서** 값이 읽히는가
/ 전시 모드를 끄면 **원래 크기로 돌아오는가**

> 💡 **색만으로 알리면 안 되는 이유** — 색을 구분하기 어려운 사람이 전시회에 옵니다.
> 그리고 멀리서는 작은 색 점이 잘 안 보입니다. **글자가 가장 확실합니다.**

## 미션 3 · 관람객이 읽는 작품 설명

지금 「이 작품은?」 에는 보통 이렇게 적혀 있습니다.

```
Frontend : Next.js + TypeScript
UI       : Tailwind CSS + Lucide React
Hardware : Raspberry Pi Pico 2 W
```

**관람객은 이걸 궁금해하지 않습니다.** 그리고 **버튼을 눌러 모달을 열지도 않습니다.**

```
작품 설명을 관람객용으로 바꿔 주세요.

- 지금 모달 안에 있는 기술 스펙(Next.js, Tailwind 같은 것)을 빼고,
  아래 세 가지를 쉬운 말로 적을 자리를 만들어 주세요.
    1. 이 작품이 무엇을 하는 물건인지 (한 문장)
    2. 어떻게 동작하는지 (두세 문장)
    3. 관람객이 직접 해 볼 수 있는 것 한 가지
- 전시 모드에서는 모달이 아니라 화면에 늘 보이는 카드로 띄워 주세요.
  관람객은 버튼을 누르지 않습니다.

대시보드 page.tsx 전체 완성본으로 주세요.
```

**직접 적을 것** — AI 가 대신 못 씁니다. 우리 작품은 우리가 제일 잘 압니다.

| | 적어 보기 |
|---|---|
| 무엇을 하는 물건인가 (한 문장) | |
| 어떻게 동작하는가 | |
| **관람객이 해 볼 것 하나** | |

> 🎯 **세 번째 칸이 전시의 성패를 가릅니다.** *"조도 센서를 손으로 가려 보세요"* 한 줄이
> 있으면 관람객이 멈춰 섭니다. 없으면 지나갑니다.

## 마무리 · 무인 리허설 30분

**지금부터 30분 동안 아무도 손대지 않습니다.** 그동안 아래를 확인합니다.

- [ ] 전시 모드를 켜 두고 **30분 뒤에도 화면이 켜져 있다**
- [ ] 중간에 가상 Pico 창에 **`x`** 를 쳐서 끊었다가 → **저절로 ONLINE 으로 돌아왔다**
- [ ] 30분 내내 **오류 화면이 한 번도 안 떴다**
- [ ] 센서 카드에 **「데이터 없음」이 없다**
- [ ] 노트북 **전원 어댑터가 꽂혀 있다**

> ⚠️ **리허설 중에 코드를 고치지 마세요.** 고쳤으면 **30분을 처음부터** 다시 셉니다.

### 전시 이틀 전부터는 코드를 그만 고칩니다

마지막에 고친 것이 당일에 터집니다. **잘 되는 상태에서 멈추는 것**도 실력입니다.
고치고 싶은 것이 생기면 적어만 두세요.

### 전시 당일 아침 점검표

- [ ] 공유기가 켜져 있고, **Pico 와 노트북이 같은 공유기**에 붙었다
- [ ] Pico 시리얼 모니터에서 **IP 를 확인**하고 화면에 넣었다
- [ ] **배선 사진과 대조**해서 빠진 선이 없다
- [ ] 센서 값이 **전부 들어온다** (「데이터 없음」이 없다)
- [ ] **전시 모드를 켰다**
- [ ] 전시 모드에서 **관람객이 눌러도 되는 버튼만** 남아 있다
      (펌프 · 모터 · 히터는 숨김 또는 자동 꺼짐)
- [ ] 노트북 **전원 어댑터**를 꽂았다
- [ ] 관람객이 **해 볼 수 있는 것**이 화면에 적혀 있다

## 오류가 났을 때 · 규칙을 어겼을 때

11주차의 **프롬프트 5 · 6** 을 그대로 씁니다.
오류 메시지는 `F12` → `Console` 에서 **그대로** 복사하세요.

### 오늘 AI 가 자주 틀리는 것

| 증상 | 어떻게 |
|---|---|
| `globals.css` 에 `@theme` 을 만들자고 한다 | 우리는 `const UI` 객체입니다. 프롬프트 6 |
| Wake Lock 을 `try/catch` 없이 쓴다 | 지원 안 하는 브라우저에서 화면이 하얘집니다 |
| 전체화면만 끄고 전시 모드는 켜 둔다 | `fullscreenchange` 처리가 빠진 것입니다 |
| 전시 모드에서 조작 버튼을 안 숨긴다 | 관람객이 눌러서 꺼 버립니다 |
| 작품 설명을 기술 스펙으로 다시 쓴다 | 관람객이 읽을 말로 **직접** 적으세요 |
