# 🚨 오늘 가장 먼저 알아야 할 것 — 제미나이는 **실행할 수 없습니다**

오늘 쓰는 프롬프트는 원래 **저장소를 직접 읽고 파일을 고치는 AI 도구**(Claude Code 같은 것)
용으로 만들어진 것을 **채팅용으로 고친** 것입니다. 그래서 **채팅으로는 못 하는 것**이 있습니다.

| 제미나이가 못 하는 것 | 그런데 「했다」고 말합니다 | 그 일은 **누가** 하나 |
|---|---|---|
| 폴더를 열어 보기 | "프로젝트 구조를 확인했습니다" | 우리가 **올린 두 파일이 전부**입니다 |
| `npm run build` · 타입 검사 · 린트 | **"타입 오류 0건입니다"** | **학생이** 직접 돌립니다 |
| 브라우저로 화면 열기 | **"반응형을 확인했습니다"** | **학생이** `F12` 로 봅니다 |
| 파일 저장 | "파일을 수정했습니다" | **학생이** 복사해 붙여넣습니다 |

> 🚨 **AI 가 「검사했습니다 · 확인했습니다 · 통과했습니다」라고 하면 그것은 거짓입니다.**
> 올린 파일을 **읽기만** 했을 뿐입니다. 나쁜 뜻이 아니라, 원래 그렇게 말하도록 만들어져 있습니다.
> **그래서 오늘 AI 에게 받는 것은 「확인 결과」가 아니라 「확인할 목록」입니다.**
> **통과·실패를 적는 사람은 우리입니다.** 이것이 오늘 배우는 것의 절반입니다.

| 지키지 않으면 | 전시장에서 무슨 일이 나나 |
|---|---|

| Wake Lock 의 `try/catch` | 지원 안 하는 브라우저에서 **화면이 하얘집니다** |
| **자동 재연결** | Wi-Fi 가 한 번 끊기면 **몇 시간 멈춘 화면**이 걸립니다 |
| 연결 상태 세 가지 | 「연결됨 / 끊김」만 남으면 **재연결 중인지 알 수 없습니다** |
