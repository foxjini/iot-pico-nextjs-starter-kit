# 14주차 · 바이브 코딩으로 화면 다듬기 — 아이콘 · 휴대폰 · 반응

노션 교재 **「14주차」** 의 배포 파일입니다.

13주차는 **완성본을 붙여넣으며** Tailwind 를 익혔습니다.
14주차는 **학생이 AI에게 부탁해서 직접 고칩니다.** 완성본을 나눠주지 않습니다.

학생들은 18세 미만이라 AI 에이전트형 도구(Claude Code, Codex, Antigravity 등)에 제약이 있어,
**학교 구글 계정의 제미나이 채팅**에 소스와 규칙 문서를 올리고 프롬프트로 요청하는
**컨텍스트 엔지니어링 방식**을 씁니다. 11주차와 같은 방법이고, 대상만 화면으로 바뀝니다.

## 오늘의 핵심 — 좁게 올린다

11주차 `bundle-source.js` 는 프로젝트를 **전부** 묶었습니다. 오늘 쓰는 `bundle-ui.js` 는
**보이는 부분만** 묶습니다.

| | `bundle-source.js` (11주차) | `bundle-ui.js` (14주차) |
|---|---|---|
| 대상 프로젝트 | `iot-week2-api` (Bootstrap) | `iot-tailwind` |
| 넣는 것 | 프로젝트 전체 `.ts .tsx .js .css .json .py` | `src/app/**` 의 `.tsx .css` + `package.json` + `postcss.config.mjs` |
| 빼는 것 | `.env*`, `settings.toml`, `node_modules/` … | 위에 더해 **`src/app/api/**`, `src/lib/**`,** `src/app/page.tsx` |
| 결과 파일 | `우리팀-소스.md` | `우리팀-UI.md` (스마트팜 기준 **17.8 KB**) |

**통신 코드가 안 올라가면 AI 가 통신 코드를 건드릴 수 없습니다.** 망가뜨리면 안 되는 것을
아예 안 보여주는 것 — 이것이 오늘 가르치는 컨텍스트 엔지니어링입니다.

생성된 `우리팀-UI.md` 맨 앞에는 **AI 에게 주는 지시문이 자동으로 들어갑니다**
(무엇을 고치고 무엇을 건드리면 안 되는지). 학생이 규칙 문서를 깜빡 안 올려도 최소한의 방어가 됩니다.

### 자동으로 빠지는 것

| 대상 | 이유 |
|---|---|
| `.env*` · `settings.toml` | 비밀번호 — **있으면 「🔒 빼냈다」고 화면에 찍어 줍니다** |
| `src/app/api/**` · `src/lib/**` | 서버·DB 코드. 오늘 고칠 것이 아닙니다 |
| `src/app/page.tsx` | `create-next-app` 기본 화면. 우리가 안 건드린 파일입니다 |
| `node_modules/` · `.next/` · `public/` | 용량·불필요 |

코드에 직접 박아둔 비밀번호도 찾아서 **줄 번호와 함께 경고**합니다.
`tailwind.config.js` 가 있으면 **v4 에는 없어야 하는 파일**이라고 알려 줍니다.

## 세 가지 미션

| 미션 | 배우는 것 | 확인 |
|---|---|---|
| 1 · Icon | `lucide-react`, **아이콘은 글자를 대신하지 않는다**, `aria-hidden` | 카드마다 아이콘 + 글자가 **둘 다** 있는가 |
| 2 · Responsive | 390px, 좁은 쪽부터, `text-5xl sm:text-6xl` | 휴대폰 폭에서 **가로 스크롤이 없는가** |
| 3 · Interaction | `hover:` `active:` **`focus-visible:`** `disabled:` `peer-focus-visible:` | **탭 키**로는 테두리가 뜨고 **마우스 클릭**에는 안 뜨는가 |

### 왜 `focus` 가 아니라 `focus-visible` 인가

`focus:` 를 쓰면 마우스로 클릭할 때도 테두리가 떠서 지저분합니다.
`focus-visible:` 은 브라우저가 "이 사람은 키보드를 쓰는 중"이라고 판단했을 때만 걸립니다.
**마우스 사용자에게는 안 보이고 키보드 사용자에게는 보이는 것** — 14주차의 숨은 주인공입니다.

스위치는 진짜 체크박스가 `sr-only` 로 숨겨져 있으므로, 초점 표시를 **형제인 트랙**에
`peer-focus-visible:` 로 겁니다. 13주차의 `peer-checked:` 와 같은 원리입니다.

## 선생님용 메모

- **가장 흔한 실패는 "아이콘만 남기고 글자를 지우는 것"입니다.** AI 가 깔끔해 보이게 하려고
  그렇게 합니다. 규칙 §7-6 과 프롬프트 6 으로 되돌리게 하세요. *전시회에는 여러 사람이 옵니다* 가
  설명하기 좋은 이유입니다.
- **`focus-visible` 을 눈으로 보여주는 것이 오늘의 좋은 수업거리입니다.** 탭 키를 눌러 테두리가
  옮겨 다니는 것을 먼저 보여주고, 같은 버튼을 마우스로 클릭해 **안 뜨는 것**을 보여주세요.
- **AI 가 `tailwind.config.js` 를 만들라고 하는 일이 잦습니다.** 인터넷에 v3 자료가 훨씬 많기
  때문입니다. `bundle-ui.js` 가 그 파일을 감지하면 경고를 찍습니다.
- 측정할 때 주의 — **`transition` 때문에 바뀌는 중의 색이 잡힙니다.** 색을 확인할 때는
  0.5초쯤 기다렸다가 보세요 (제가 검증하다 세 번 속았습니다).
