## 세 가지 미션

| 미션 | 시간 | 하는 일 | 왜 전시에 필요한가 |
|---|---|---|---|
| **1 · 전시 모드** | 30분 | WakeLock + 전체화면 + **조작 버튼 숨기기** | 화면이 꺼지면 **작품이 고장 난 것처럼 보입니다.** 관람객이 버튼을 눌러 꺼 버립니다 |
| **2 · 멀리서도 보이게** | 25분 | 전시 모드에서만 값 크게, 상태를 **색+아이콘+글자** | 관람객은 **1m 밖에서** 봅니다 |
| **3 · 작품 설명** | 25분 | 기술 스펙 → **관람객이 읽는 말**, 전시 모드에서는 **늘 보이는 카드** | 관람객은 **버튼을 안 누릅니다** |
| 마무리 | 30분 | **무인 리허설** + 당일 아침 점검표 | 마지막에 고친 것이 당일 터집니다 |

### 미션 1에서 절대 빠지면 안 되는 한 줄

```tsx
// ESC 로 전체화면을 빠져나와도 전시 모드가 같이 꺼지게
useEffect(() => {
  const onFsChange = () => { if (!document.fullscreenElement) setKiosk(false); };
  document.addEventListener("fullscreenchange", onFsChange);
  return () => document.removeEventListener("fullscreenchange", onFsChange);
}, []);
```

이게 없으면 전시 중에 누가 **ESC 를 눌렀을 때 조작 버튼이 숨겨진 채로 남아** 되돌릴 방법이
없어집니다. 새로고침밖에 없습니다. 프롬프트에 `★` 로 적어 두었지만, **AI 가 가장 자주 빼먹는 것**입니다.

### WakeLock 은 탭을 옮기면 풀립니다

`navigator.wakeLock.request("screen")` 은 **탭이 숨겨지면 자동으로 해제**됩니다.
`visibilitychange` 에서 다시 걸지 않으면, 전시 중 한 번 다른 창을 봤다 돌아온 뒤부터
화면이 꺼집니다. 그리고 **지원하지 않는 브라우저가 있으니 `try/catch`** 로 감싸야 합니다
(감싸지 않으면 화면이 하얗게 됩니다).

## 오늘의 핵심 — 좁게 올린다

11주차 `bundle-source.js` 는 프로젝트를 **전부** 묶었습니다. 오늘 쓰는 `bundle-ui.js` 는
**보이는 부분만** 묶습니다.

| | `bundle-source.js` (11주차) | `bundle-ui.js` (14주차) |
|---|---|---|
| 넣는 것 | 프로젝트 전체 `.ts .tsx .js .css .json .py` | `src/app/**` 의 `.tsx .css` + `package.json` + `postcss.config.mjs` |
| 빼는 것 | `.env*`, `settings.toml`, `node_modules/` … | 위에 더해 **`src/app/api/**`, `src/lib/**`,** `src/app/page.tsx` |
| 결과 파일 | `우리팀-소스.md` | `우리팀-UI.md` |

**통신 코드가 안 올라가면 AI 가 통신 코드를 건드릴 수 없습니다.** 망가뜨리면 안 되는 것을
아예 안 보여주는 것 — 이것이 오늘 가르치는 컨텍스트 엔지니어링입니다.

> 🔒 **학생 프로젝트에는 2주차 MySQL 접속 정보가 들어 있습니다.**
> `src/app/api/` · `src/lib/db.ts` · `.env.local` 이 전부 빠지는 것을 **눈으로 확인**하고 올리세요.

생성된 `우리팀-UI.md` 맨 앞에는 **AI 에게 주는 지시문이 자동으로 들어갑니다**
(무엇을 고치고 무엇을 건드리면 안 되는지). 학생이 규칙 문서를 깜빡 안 올려도 최소한의 방어가 됩니다.

### 자동으로 빠지는 것

| 대상 | 이유 |
|---|---|
| `.env*` · `settings.toml` | 비밀번호 — **있으면 「🔒 빼냈다」고 화면에 찍어 줍니다** |
| `src/app/api/**` · `src/lib/**` | 서버·DB 코드. 오늘 고칠 것이 아닙니다 |
| `src/app/page.tsx` | `create-next-app` 기본 화면. 우리가 안 건드린 파일입니다 |
| `node_modules/` · `.next/` · `public/` | 용량·불필요 |

코드에 직접 박아둔 비밀번호도 찾아서 **줄 번호와 함께 경고**합니다.
`tailwind.config.js` 가 있으면 **v4 에는 없어야 하는 파일**이라고 알려 줍니다.

## 선생님용 메모

- **전시 모드에서 조작 버튼을 숨기는 것이 오늘의 진짜 교육 내용입니다.** "관람객이 눌러서
  꺼 버린다"는 이유를 먼저 말해 주세요. 기능이 아니라 **사용자를 생각한 설계**입니다.
- **미션 3의 세 번째 칸("관람객이 해 볼 것 하나")이 전시의 성패를 가릅니다.**
  *"조도 센서를 손으로 가려 보세요"* 한 줄이 있으면 관람객이 멈춰 섭니다. 없으면 지나갑니다.
  **이것은 AI 가 대신 못 씁니다** — 우리 작품은 우리가 제일 잘 압니다.
- **AI 가 `tailwind.config.js` 를 만들라고 하는 일이 잦습니다.** 인터넷에 v3 자료가 훨씬 많기
  때문입니다. `bundle-ui.js` 가 그 파일을 감지하면 경고를 찍습니다.
- **`@theme` 블록을 만들자고 하면 거절하게 하세요.** 학생 코드는 `const UI` 객체입니다.
  규칙 문서 §3-4 와 프롬프트 6 으로 되돌립니다.
- **전시 이틀 전부터는 코드를 그만 고치게 하세요.** "잘 되는 상태에서 멈추는 것"도 실력입니다.
- 측정할 때 주의 — **`transition` 때문에 바뀌는 중의 색이 잡힙니다.** 색을 확인할 때는
  0.5초쯤 기다렸다가 보세요 (제가 검증하다 세 번 속았습니다).
  그리고 **헤드리스 Chromium 은 `requestFullscreen()` 을 허용하지만 ESC 는 안 먹습니다** —
  자동 시험에서는 `document.exitFullscreen()` 을 부르세요.
