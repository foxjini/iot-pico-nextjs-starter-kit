### 🚨 전시 모드 코드는 **나눠 줍니다** — AI 가 새로 쓰지 않습니다

`page_exhibit_reference.tsx` 의 `★ 14주차` 두 덩어리(원본 **229~268행**)를
매뉴얼 단계 J1 에 **그대로 실어 두었습니다.** AI 에게는 **「어디에 넣고 무엇을 연결하는가」만**
묻게 했습니다.

**왜 이것만 예외인가** — 센서·액추에이터는 팀마다 다르지만 **Wake Lock 은 모든 팀이
똑같습니다.** 팀마다 다를 이유가 없는 코드를 매번 플래시가 새로 쓰면 **매번 다르게 틀립니다.**
그리고 **14주차가 마지막 수업이라 전시 모드가 깨지면 되돌릴 기회가 없습니다.**
학생이 직접 받아내는 것은 **주인공 · 액추에이터 안전 · 작품 설명**에 그대로 남아 있습니다.

### 전시 모드에서 가장 자주 빠지는 것 — `fullscreenchange`

전시 모드에서는 조작 버튼이 숨어 있습니다. 누가 <kbd>ESC</kbd> 를 누르면 **전체화면만
풀리는데**, 그러면 **버튼이 숨겨진 채로 남아 아무것도 못 하게 됩니다.** 새로고침밖에 없습니다.

### WakeLock 은 탭을 옮기면 풀립니다

`navigator.wakeLock.request("screen")` 은 **탭이 숨겨지면 자동 해제**됩니다.
`visibilitychange` 에서 다시 걸지 않으면 **한 번 다른 창을 봤다 돌아온 뒤부터** 꺼집니다.
그리고 **지원하지 않는 브라우저가 있어 `try/catch` 가 없으면 화면이 하얘집니다.**

### 액추에이터 안전 — 전시 모드는 버튼을 막아 주지 않습니다

전시 모드를 켜도 **11주차에 만든 액추에이터 버튼은 그대로 눌립니다.** 가상 Pico 로
재어 보니 관람객이 누른 명령이 **Pico 까지 가서 적용**됐습니다.
**다만 전부 숨기는 것도 답이 아닙니다** — 관람객이 해 볼 거리가 없어집니다.
**LED · 부저는 남기고, 펌프 · 모터 · 히터만** 가리게 했습니다.

## 오늘의 핵심 — 좁게 올린다

11주차 `bundle-source.js` 는 프로젝트를 **전부** 묶었습니다. 오늘 쓰는 `bundle-ui.js` 는
**보이는 부분만** 묶습니다.

| | `bundle-source.js` (11주차) | `bundle-ui.js` (14주차) |
|---|---|---|
| 넣는 것 | 프로젝트 전체 `.ts .tsx .js .css .json .py` | `src/app/**` 의 `.tsx .css` + `package.json` + `postcss.config.mjs` |
| 빼는 것 | `.env*`, `settings.toml`, `node_modules/` … | 위에 더해 **`src/app/api/**`, `src/lib/**`,** `src/app/page.tsx` |
| 결과 파일 | `우리팀-소스.md` | `우리팀-UI.md` |

**통신 코드가 안 올라가면 AI 가 통신 코드를 건드릴 수 없습니다.** 망가뜨리면 안 되는 것을
아예 안 보여주는 것 — 이것이 오늘 가르치는 컨텍스트 엔지니어링입니다.

> 🔒 **학생 프로젝트에는 2주차 MySQL 접속 정보가 들어 있습니다.**
> `src/app/api/` · `src/lib/db.ts` · `.env.local` 이 전부 빠지는 것을 **눈으로 확인**하고 올리세요.

생성된 `우리팀-UI.md` 맨 앞에는 **AI 에게 주는 지시문이 자동으로 들어갑니다**
(무엇을 고치고 무엇을 건드리면 안 되는지). 학생이 규칙 문서를 깜빡 안 올려도 최소한의 방어가 됩니다.

### 자동으로 빠지는 것

| 대상 | 이유 |
|---|---|
| `.env*` · `settings.toml` | 비밀번호 — **있으면 「🔒 빼냈다」고 화면에 찍어 줍니다** |
| `src/app/api/**` · `src/lib/**` | 서버·DB 코드. 오늘 고칠 것이 아닙니다 |
| `src/app/page.tsx` | `create-next-app` 기본 화면. 우리가 안 건드린 파일입니다 |
| `node_modules/` · `.next/` · `public/` | 용량·불필요 |

코드에 직접 박아둔 비밀번호도 찾아서 **줄 번호와 함께 경고**합니다.
`tailwind.config.js` 가 있으면 **v4 에는 없어야 하는 파일**이라고 알려 줍니다.

## 선생님용 메모

- **19단계를 다시 하지 않는 것**이 이번 개편의 전부입니다. 학생이 *"14주차에 뭘 더 하지?"*
  하고 물으면 — **더 예쁘게 만드는 시간이 아니라, 전시장에서 버티게 만드는 시간**이라고
  말해 주세요. 기능이 되는 것과 **무인 몇 시간을 버티는 것**은 다릅니다.
- **전시 모드 코드를 나눠 주는 것**이 *"완성본을 나눠주지 않는다"* 는 원칙과 어긋나 보입니다.
  맞습니다 — **전시 모드에 한해** 굽혔습니다. 판단 근거는 위 「왜 이것만 예외인가」 입니다.
- **「미검증」을 「통과」로 적지 않게** 하세요. 실물 Pico 가 없어 확인 못 한 것은 미검증이고,
  그것이 **전시 전에 해야 할 일 목록**입니다. 통과로 적으면 그 목록이 사라집니다.
- **가상 Pico 로만 개발한 팀**은 **무인 리허설 전에** 실물로 옮겨야 합니다
  (매뉴얼 단계 15). 전시장에는 가상 Pico 가 없습니다.
- **전시 이틀 전부터는 코드를 그만 고치게** 하세요. 마지막에 고친 것이 당일에 터집니다.
