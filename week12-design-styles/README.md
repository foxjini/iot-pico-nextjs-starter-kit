# 12주차 · 디자인 스타일과 레이아웃 고르기

노션 교재 **「12주차 · 디자인 스타일과 레이아웃 고르기」** 의 코드 원본입니다.

| 파일 | 내용 |
|---|---|
| `globals.css` | 스타일 4종 정의 — `src/app/globals.css` 에 전체 교체 |
| `page_week12.tsx` | 전환 막대 + 레이아웃 3종 (11주차 모범답안 기준 전체 완성본) |

학생 파일은 11주차에 팀마다 다르게 받았으므로, 교재에는 **★ 표시된 다섯 덩어리만** 옮기도록 안내했습니다.

## 구조

스타일은 `<html data-style="...">` 한 글자로 바뀝니다. 기능 코드는 건드리지 않습니다.

```
flat   기본 (Bootstrap dark)
min    미니멀리즘 — 그림자 없음, 얇은 테두리
neu    뉴모피즘   — 카드와 배경이 같은 색, 그림자 두 개로 구분
glass  글래스모피즘 — backdrop-filter 로 뒤가 비침
```

레이아웃은 `grid`(균등) / `hero`(대형 강조) / `side`(사이드바) 세 가지이고,
`hero` 는 **SENSORS 배열의 첫 번째**를 주인공으로 삼습니다.

## 명암비 측정 결과 (WCAG 공식 식으로 계산)

### 글자 대비 — 기준 4.5:1, 전부 통과

| 스타일 | 글자 vs 카드 |
|---|---|
| 기본 | 11.14 : 1 ○ |
| 미니멀리즘 | 13.83 : 1 ○ |
| 뉴모피즘 | 12.72 : 1 ○ |
| 글래스모피즘 | 9.83 : 1 ○ |

### 경계 대비 — 기준 3:1, 전부 미달

| 스타일 | 무엇과 무엇 | 명암비 |
|---|---|---|
| 기본 | 카드 vs 배경 | 1.16 : 1 ✗ |
| 미니멀리즘 | 테두리(0.14) vs 카드 | 1.54 : 1 ✗ |
| 뉴모피즘 | 어두운 그림자 vs 카드 | 1.15 : 1 ✗ |
| 뉴모피즘 | 밝은 그림자 vs 카드 | 1.18 : 1 ✗ |
| 글래스모피즘 | 테두리 vs 카드 | 1.75 : 1 ✗ |

### 고칠 수 있는가 — 여기서 갈린다

미니멀리즘 테두리 투명도를 올리면:

| 투명도 | 명암비 |
|---|---|
| 0.14 | 1.54 : 1 ✗ |
| 0.30 | 2.70 : 1 ✗ |
| **0.40** | **3.78 : 1 ○** |

→ 이 교재의 `globals.css` 는 **0.40** 으로 넣었습니다.

뉴모피즘 그림자를 세게 하면:

| 그림자 | 명암비 |
|---|---|
| 지금 값 | 1.15 : 1 ✗ |
| **완전 검정** | **1.38 : 1 ✗** |
| 훨씬 밝게 | 2.65 : 1 ✗ |

→ **값 조절로는 3:1을 넘을 수 없습니다.** 카드와 배경이 같은 색이어야 뉴모피즘이기 때문입니다.
설정의 문제가 아니라 방식 자체의 한계입니다.
