# 10주차 · 우리 팀 작품으로 옮기기 — 센서 이식

노션 교재 **「10주차 · 우리 팀 작품으로 옮기기 — 센서 이식 절차」** 의 코드 원본입니다.

| 파일 | 내용 |
|---|---|
| `main_week10_example.py` | Pico — 기존 5개 + 추가 4종 + 릴레이를 전부 붙인 예시 |
| `page_week10_example.tsx` | 화면 — 센서 9개 + 펌프 스위치 (`src/app/dashboard/page.tsx`) |
| `sensor-tests/code_*.py` | **센서 하나만 시험하는 최소 코드** (`CIRCUITPY/code.py` 로 저장) |
| `mock-pico10.js` | 하드웨어 없이 화면만 확인하는 모의 서버 |

## 이식 절차 7단계

| 단계 | 하는 일 | 넘어가는 조건 |
|---|---|---|
| 1 | 핀 정하기 | 배정표에 적었고 기존 핀과 안 겹친다 |
| 2 | 전원·전압 확인 | **신호선이 5V를 내보내는가**를 답할 수 있다 |
| 3 | 배선 | USB를 뽑은 상태에서 연결했다 |
| 4 | **`code.py`로 값만 출력** | 시리얼에 숫자가 뜨고, 센서를 건드리면 바뀐다 |
| 5 | 값 다듬기 | 단위·범위가 맞고, 실패하면 `None`을 돌려준다 |
| 6 | payload에 키 추가 | `[WS] 송신 메시지`에 키가 늘었다 |
| 7 | 화면 배열에 추가 | 카드가 생기고 값이 들어온다 |

**4단계를 건너뛰지 말 것.** 대시보드에 바로 붙이면 값이 안 나올 때 의심할 곳이 다섯 군데가 된다.

## 핀 배정 (예시에서 쓴 것)

| 핀 | 용도 | 비고 |
|---|---|---|
| GP15 / GP16 / GP17·18·19 / GP26 | 서보 / DHT11 / RGB LED / CdS | 기존 |
| GP27 (ADC1) | 토양수분 | 3V3 전원 |
| GP14 / GP13 | 초음파 TRIG / ECHO | **ECHO에 분압 1k+2k 필수** (또는 HC-SR04P) |
| GP12 | PIR OUT | 5V 전원, 출력은 3.3V |
| GP4 / GP5 | 미세먼지 UART TX / RX | **5V 전원**, 데이터선은 3.3V. TX↔RX 엇갈려 연결 |
| GP20 | 릴레이 IN | 5V 전원. 대부분 active-low |

**GP23 · GP24 · GP25 · GP29 는 쓰지 말 것** — Pico 2 W의 무선 칩과 전원 제어가 쓰는 핀.

## 검증 범위 (2026-09-19)

| 항목 | 상태 |
|---|---|
| 화면 코드 (센서 9개 + 펌프) | ✅ 타입 오류 0건 / 콘솔 오류 0건 / 프로덕션 빌드 성공 |
| 모의 Pico 연동 | ✅ 카드 9장 렌더링, 미세먼지 경고(82 ≥ 75), `pump: 255` 전송 확인 |
| 자동 모드 범위 분리 | ✅ 자동 모드 ON 시 LED 3개만 잠기고 펌프는 조작 가능 |
| Pico 코드 | ✅ 문법 검사 통과, 토양수분 환산식 계산 확인 |
| 라이브러리 사용법 | ✅ Adafruit 공식 문서 대조 (`adafruit_hcsr04`, `adafruit_pm25`) |
| **실제 센서 배선·동작** | **❓ 미검증** — 집필 환경에 부품 없음. `code.py`로 하나씩 확인할 것 |

## 모의 Pico 서버

```bash
node mock-pico10.js                # 보통

MODE=broken node mock-pico10.js    # 초음파·미세먼지 측정 실패(null) — "값 없음" 확인
```
