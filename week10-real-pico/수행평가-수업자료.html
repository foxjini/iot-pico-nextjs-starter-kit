02 · 전원

전기는 두 갈래 — 5V 와 3.3V

브레드보드 왼쪽 레일은 외부 5V 어댑터, 오른쪽 레일은 Pico 의 3.3V. GND(−)는 모두 하나로 잇습니다.

모터에 왜 따로 어댑터가 필요할까?

전원 순서 켤 때 USB 먼저 → 어댑터, 끌 때 · 선을 바꿀 때 어댑터 먼저.
RC522 는 3.3V 전용 — 5V 레일에 꽂으면 망가질 수 있어요.

03 · 조이스틱 = 가변저항 2개 + 버튼

기울인 만큼 전압이 바뀐다

조이스틱 안의 가변저항이 3.3V 를 나눠 0~3.3V 를 내보내고, Pico 의 ADC 가 이것을 0~65535 숫자로 읽습니다.

X 기울이기 0%

「+5V」 핀에는 3.3V 를!

핀 이름은 +5V 지만, 5V 를 넣으면 출력이 Pico ADC 한계(3.3V)를 넘습니다.

버튼 (SW)

누르면 LOW(0). Pico 안의 풀업 저항이 평소엔 HIGH 로 잡아 줍니다.
누르면 → LCD 원래대로 + 모터 위치 0°

04 · 스텝모터 28BYJ-48 + ULN2003

코일 4개를 차례로 켜면 한 칸씩 돈다

Pico 는 약한 신호만 보내고, ULN2003 이 외부 5V 로 코일에 전류를 흘립니다. 반 스텝 4096 번 = 한 바퀴(기어 1:64).

안쪽 자석(회전자)은 켜진 코일 쪽으로 끌려갑니다. 천천히 보여 주는 그림 — 실제로는 1초에 수백 번 바뀝니다.

05 · LCD 1602 + I2C + 레벨 변환

선 2개로 LCD 에 글자를 보낸다

I2C: SDA(데이터) · SCL(박자) 두 선에 주소 0x27 을 붙여 보냅니다. LCD 는 5V, Pico 는 3.3V 라 가운데에 레벨 변환이 필요해요.

왜 레벨 변환?

LCD 뒤 I2C 모듈의 풀업 저항이 SDA · SCL 을 5V 까지 올립니다. 그대로 이으면 3.3V 용 Pico 핀에 5V 가 들어가요.

속도는 충분할까? — 예

  • 100kHz (LCD 의 PCF8574 최대) · 신호 오르는 시간 0.2~0.5μs < 허용 1μs
  • 글자 1개 ≈ 0.6ms · 두 줄 전체 ≈ 20ms
  • 주소는 0x27 또는 0x3F — 코드가 알아서 찾음
06 · RFID-RC522 + SPI

카드와 리더기의 짧은 대화

RC522 는 13.56MHz 전파로 카드와 이야기하고, Pico 와는 SPI(SCK · MOSI · MISO · SDA 4선)로 빠르게 주고받습니다.

카드 번호 → ASCII 글자

16진수 두 자리 = 1바이트(0~255). 0x20~0x7E 이면 글자로, 아니면 「.」

07 · 조이스틱 Y 로 LCD 표시 돌리기

전광판처럼 — 글자가 사라지지 않고 돈다

Y 를 위(+)로 → 오른쪽으로 한 칸씩, 아래(−)로 → 왼쪽으로. 끝으로 나간 글자는 반대쪽에서 다시 나옵니다. 버튼 = 원래대로.


돌린 칸 수 0 — 코드: 줄[16−k:] + 줄[:16−k] (오른쪽으로 k칸) · 조금 기울이면 0.4초, 끝까지 기울이면 0.12초 간격 · 새 카드를 대면 0칸부터

08 · 10cm 점퍼선에 맞춘 배치

세 모듈을 180° 돌려 놓는다

점퍼선이 짧아서 핀이 Pico 쪽을 보게 돌립니다 — 레벨 변환기 · LCD · RC522. LCD 글씨는 코드가 뒤집어 그려요.

LCD — 돌려 놓으면 글씨가 거꾸로?

LCD_FLIP 은 어떻게 뒤집을까?

  • LCD 칩에는 화면을 뒤집는 기능이 없어요.
  • 그래서 글자마다 180° 돌린 모양을 직접 그려 「사용자 글자 8칸」 에 넣고, 줄 순서 · 글자 순서도 거꾸로 씁니다.
  • 0 · 8 · H · I · N · O · S · X · Z 와 6↔9 는 돌려도 같은 글자라 칸을 안 씀.
  • 한 화면에 그 밖의 글자가 8종류를 넘으면 비슷한 글자로 대신 나와요.
