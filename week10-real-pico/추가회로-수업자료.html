추가 회로 원리초음파 · 포토커플러 + 릴레이 · PWM LED

오늘 만들 회로 — 원리 4가지

부품이 왜 그 자리에 있는지 알고 꽂으면 실수가 줄어듭니다.

1저항으로 전압 나누기

V(GP11) = 5V × R2 ÷ (R1 + R2) — 전압은 저항 크기에 비례해서 나뉩니다.

5V 를 그대로 GP11 에 넣으면 Pico 가 망가질 수 있습니다 (입력 최대 3.3V).

2포토커플러 PC817 — 빛으로 건너는 신호

입력과 출력 사이에 전선이 없습니다. LED 빛을 받아 트랜지스터가 켜집니다 = 절연.

REA — 부품을 역공학하기

겉모습 → 분해 → 동작 순서로 열고, 알게 된 것을 셋으로 나눕니다.
관찰 — 눈으로 확인
  • 기판 인쇄 IN1 · G / V1 · G, 채널 2개
  • 검은 4핀 칩 2개 · 노란 점퍼 2개
  • 칩 옆 작은 저항 · 빨간 표시 LED
추론 — 근거로 짐작
  • 입력 = 저항 → 표시 LED → 칩 LED 직렬
    → 그래서 3.6V 이상 필요 (Pico 3.3V 로는 부족)
  • 그래서 IN1 = 5V, G = GP13 으로 끌어내려 켬
모름 — 아직 확인 못 함
  • 노란 점퍼가 정확히 무엇을 잇는지 → 뽑아 두고 사용
  • 내장 저항 값

3릴레이 — 전자석으로 누르는 스위치

작은 전류(Signal)로 코일을 켜면, 전자석이 쇠판을 당겨 큰 전류(모터)의 스위치가 「딸깍」 바뀝니다.

REA — 부품을 역공학하기

겉모습 → 분해 → 동작 순서로 열고, 알게 된 것을 셋으로 나눕니다.
관찰 — 눈으로 확인
  • 릴레이 인쇄 5VDC · 10A 250VAC · JQC-3FF-S-Z
  • 단자 NO · COM · NC, 핀 GND · 5V · Signal
  • 기판에 작은 부품 몇 개 + 확인 LED
추론 — 근거로 짐작
  • 코일 5V · 약 70mA (같은 형번 데이터시트)
    → Pico 핀으로는 직접 못 켬
  • 작은 부품 = 트랜지스터 · 다이오드 · 저항
    → Signal 의 작은 전류로 코일을 켬
모름 — 아직 확인 못 함
  • Signal HIGH · LOW 중 어디서 켜지는지
    → 키트로 확인

4PWM — 켜져 있는 시간의 비율

아주 빠르게 켜고 끄면, 눈은 깜빡임 대신 평균 밝기를 봅니다. duty(%) = HIGH 시간 ÷ 한 주기

한 주기 1 ms (1000 Hz)
HIGH 시간 0.50 ms
평균 전압 1.65V (3.3V × duty)
코드: led.duty_cycle = 32767
