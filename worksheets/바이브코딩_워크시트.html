바이브 코딩으로 우리 팀 작품 만들기

11주차 수업에서는 모두 같이 「교실 스마트팜」을 만들며 프롬프트 0~7을 익혔습니다. 이제 우리 팀 주제로 같은 일을 합니다. 아래 설계표에 센서와 액추에이터를 등록하면 프롬프트 0~7이 우리 팀 부품 이름·핀 번호·JSON 키로 자동으로 채워집니다. 채운 뒤에는 그대로 복사해서 생성형 AI에 붙여넣으면 됩니다.

이 워크시트는 11주차 교재와 짝입니다. 순서·규칙·검수 항목이 모두 교재와 같습니다. 막히면 week11-vibe-coding/프롬프트-모음-스마트팜.md (수업에서 한 완성형 예제)를 옆에 두고 비교하세요. 부품이 아직 없으면 mock-pico/mock_pi_11.py 를 켜고 창에 add <키> <최소> <최대> 를 치면 그 센서가 있는 것처럼 화면을 먼저 완성할 수 있습니다.

우리 팀 주제 정하기

11주차 예제(스마트팜)의 한 줄 설명이 바로 이 형식입니다.

11월 20일 안내판에 그대로 적을 문장입니다. 관람객이 1~2m 밖에서 읽습니다.

아날로그 센서는 두 개까지만 붙일 수 있습니다. Pico 2 W에 남은 아날로그 핀은 GP27, GP28 둘뿐입니다 (GP26은 CdS 조도가 쓰고 있습니다). 토양수분·가변저항·먼지센서(아날로그형)처럼 0~100으로 값이 변하는 센서가 세 개 이상이면 아래 설계표를 채우기 전에 팀에서 구성을 다시 정하세요.

우리 팀 하드웨어 입·출력(I/O) 설계표

기존 기본 부품 사용 여부와 팀별 추가 부품을 설정하세요. 핀을 잘 모를 땐 [⚡ 핀 스마트 자동 할당]을 누르세요!

기존 기본 부품 (8~10주차 베이스) 사용 여부 설정 (체크 해제 시 해당 핀이 가용 핀으로 반환되며, 프롬프트에서 제거를 지시합니다)
표에 미리 들어 있는 두 줄은 지난 시간 예제(교실 스마트팜)입니다. 우리 팀이 쓰지 않는 부품이면 삭제 버튼으로 지우고 우리 팀 부품으로 다시 채우세요.
지난 시간에는 스텝모터를 실제로 연결하지 않고 코드만 확인했지만, 우리 팀 작품은 11월 20일 전시회에 실물로 나갑니다. 여기 적는 부품은 전부 진짜로 배선할 것만 적으세요.
구분 부품명 신호 종류 Pico 연결 핀 전원 측정/제어 방식 JSON 키 삭제
Pico 2 W 핀 가이드: Wi-Fi 전용 핀(GP23, GP24, GP25, GP29) 및 기존 사용 핀(GP15:서보, GP16:DHT11, GP17~19:RGB, GP26:CdS)은 자동 제외되며, 아날로그 센서는 GP27, GP28에, 디지털 센서 및 액추에이터는 GP0~GP14, GP20~GP22에 안전하게 자동 배정됩니다.
스텝모터(28BYJ-48 + ULN2003)를 고르면 IN1~IN4 네 핀이 연속으로 잡힙니다 — 표에서는 첫 핀만 고르면 됩니다. 전원은 반드시 외부 5V(왼쪽 레일)에서 받으세요. 3V3에 물리면 Pico가 재부팅됩니다.
3단계

센서를 붙이기 전 — 전압 확인이 먼저입니다

11주차 교재 4-1절과 같은 내용입니다. 이 절은 코드 이야기가 아니라 보드가 죽는 이야기입니다.

AI는 배선을 볼 수 없습니다. 5V 센서를 물어보면 “GP27에 연결하세요”라고 태연히 답합니다. 그대로 꽂으면 Pico가 망가집니다. Pico의 GPIO는 3.3V까지입니다. 센서가 Pico로 내보내는 신호가 5V면 그 핀이 망가집니다. 전원이 5V인 것과 신호가 5V인 것은 다릅니다.
센서 전원 Pico로 나가는 신호 조치
토양수분 (정전용량식 v1.2)3.3~5.5V전원과 같은 범위3V3(오른쪽 빨강 레일)에 연결하면 안전
HC-SR04 초음파5VECHO가 5V분압(1kΩ+2kΩ) 필수 또는 HC-SR04P 사용
HC-SR501 PIR 인체감지외부 5VOUT은 3.3V그냥 연결 가능
PMS7003 미세먼지외부 5VTX는 3.3V데이터선 직결, 전원만 외부 5V
릴레이 모듈외부 5V신호를 받기만 함안전. 단 펌프·모터는 또 다른 전원. 대부분 active-low
전원과 GND — 3V3(OUT, 36번 핀)은 다 합쳐서 약 300mA까지입니다. 서보·모터·펌프를 여기서 먹이면 Pico가 꺼졌다 켜집니다. 5V가 필요하면 브레드보드 왼쪽 빨강 레일(외부 5V 어댑터)에서 받습니다 — Pico의 VBUS 핀은 쓰지 않습니다. 그리고 왼쪽 파랑 레일과 오른쪽 파랑 레일이 점퍼로 이어져 있어야 합니다. 가장 자주 빠뜨리는 선입니다.
배선 순서 — 이 순서를 지키면 안 망가집니다
센서 하나만 따로 시험하기 — code.py

대시보드에 바로 붙이면 값이 안 나올 때 의심할 곳이 다섯 군데(센서·배선·Pico 코드·화면 코드·키 이름)나 됩니다. 센서 하나만 먼저 시험하면 두 군데로 줄어듭니다. CircuitPython은 code.py 가 있으면 main.py 대신 그것을 실행하므로, 잘 돌던 main.py 를 건드리지 않고 시험할 수 있습니다.

# code.py — 센서 하나만 시험 (아날로그 센서용) import time import board import analogio sensor = analogio.AnalogIn(board.GP27) # 실제로 연결한 핀으로 바꾸세요 while True: raw = sensor.value # 0 ~ 65535 print("raw:", raw, " 백분율:", round(raw / 65535 * 100, 1)) time.sleep(0.5)
시리얼에 나온 것뜻
숫자가 변한다✅ 성공 — 다음 단계로
계속 0 이다전원(3V3) 또는 신호선이 안 닿았다
계속 65535 이다GND가 안 이어졌다
아무 숫자나 마구 튄다GND를 확인하고, 선을 짧게 하세요
No pulldown 같은 오류그 핀은 아날로그가 아닙니다. GP27 또는 GP28로
시험이 끝나면 code.py 를 지우거나 code.py.bak 으로 이름을 바꾸세요. 안 지우면 main.py 가 실행되지 않아서, 코드는 다 맞는데도 대시보드가 연결조차 안 됩니다. 이 실수가 정말 많습니다.
