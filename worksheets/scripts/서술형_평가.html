1빛 센서(CdS)의 전압 나누기

15점 · 약 8분

무드등은 왼쪽 그림처럼 10kΩ 은 3V3 쪽, CdS 는 GND 쪽에 두고 그 사이를 GP26 에 잇습니다. CdS 는 어두울수록 저항이 커지는 부품이고, 코드는 밝기(%) = 100 − (GP26 값의 %) 로 계산합니다.

(1)방이 어두워지면 GP26 의 전압은 어떻게 변하는지 까닭과 함께 쓰시오.[8점]

어두우면 CdS 저항이 커져 전압을 더 많이 나눠 가지므로(CdS 양끝 전압↑) GP26 전압이 높아진다 → 코드의 밝기 값은 낮아진다.

(2)두 부품의 자리를 바꿔 꽂으면(CdS 를 3V3 쪽, 10kΩ 을 GND 쪽) 무드등은 어떻게 동작하는지 쓰시오.[7점]

어두울 때 GP26 전압이 오히려 낮아져 코드가 「밝다」 고 판단한다 → 무드등이 원래와 정반대로 동작한다(밝을 때 켜지고 어두울 때 꺼짐).
채점 기준
  • (1) 전압이 높아진다 3점 + 까닭(CdS 저항 증가 → 큰 저항에 큰 전압) 5점. 「밝기 값 낮아짐」 은 쓰지 않아도 감점 없음.
  • (2) 「반대로 동작」 4점 + 까닭(전압 변화 방향이 뒤집힘) 3점.

2서보 모터의 전원

15점 · 약 7분

최종 배선도에서 SG90 서보의 빨강(전원)선은 Pico 의 VBUS(노트북 USB 5V)가 아니라 왼쪽 레일의 외부 5V 어댑터에 잇고, 그 레일에 470~1000μF 커패시터를 꽂았습니다.

(1)서보 전원을 노트북 USB(VBUS)에서 받으면 생기는 문제를 전류와 관련지어 쓰시오.[9점]

서보가 움직이기 시작하는 순간 700~1000mA 가 필요한데 노트북 USB 는 약 500mA 라 모자라서, 전압이 떨어지고 Pico 가 리셋(재시작)된다.

(2)레일에 꽂은 큰 커패시터가 하는 일을 쓰시오.[6점]

작은 물탱크처럼 전기를 모아 두었다가, 모터가 순간적으로 큰 전류를 쓸 때 보태 주어 전압을 안정시킨다.
채점 기준
  • (1) 기동 순간 큰 전류(700~1000mA) 필요 3점 + USB 한계(약 500mA) 3점 + 결과(전압 떨어짐 / Pico 리셋) 3점. 수치는 대략 맞으면 인정.
  • (2) 순간 전류 보충 3점 + 전압 안정(떨어짐 방지) 3점.

3공통 GND 와 전원 레일

15점 · 약 7분

최종 배선도는 왼쪽 레일 = 외부 5V · 외부 GND, 오른쪽 레일 = Pico 3V3 · GND 로 나누고, 아래쪽에 왼쪽 파랑(−) ↔ 오른쪽 파랑(−) 을 잇는 점퍼를 하나 꽂았습니다.

(1)이 공통 GND 점퍼를 빼면 서보 모터가 어떻게 되는지 까닭과 함께 쓰시오.[9점]

서보가 제멋대로 돈다(떨리거나 엉뚱한 각도). 신호(PWM) 전압은 GND 를 기준으로 재는데, GND 가 이어지지 않으면 Pico 와 서보의 기준이 달라 신호를 바르게 읽지 못하기 때문.

(2)외부 5V 를 오른쪽 레일에 넣으면 안 되는 까닭을 쓰시오.[6점]

오른쪽 레일은 Pico 3V3 자리라서, 5V 가 들어가면 3.3V 로 동작하는 부품(DHT11 · CdS 분압 → GP26)과 Pico 가 망가질 수 있다.
채점 기준
  • (1) 결과(제멋대로 돎 / 오동작) 3점 + 까닭(신호는 GND 기준 · 기준 전압이 서로 달라짐) 6점.
  • (2) 오른쪽 = 3.3V 자리 3점 + 3.3V 부품 · Pico 손상 3점.

4초음파 센서 ECHO 의 전압 나누기

20점 · 약 9분

HC-SR04 의 ECHO 핀은 5V 신호를 내보냅니다. 그래서 왼쪽 그림처럼 1kΩ(ECHO 쪽) + 2kΩ(GND 쪽) 으로 나눈 점을 GP11 에 잇습니다.

참고: 큰 저항에 큰 전압이 걸린다 · V(GP11) = 5V × (GND 쪽 저항) ÷ (두 저항의 합) · Pico 는 약 2V 이상을 HIGH 로 읽음

(1)ECHO 가 5V 일 때 GP11 의 전압을 풀이와 함께 구하시오.[8점]

5V × 2kΩ ÷ (1kΩ + 2kΩ) = 5 × 2/3 ≈ 3.33V

(2)두 저항을 바꿔 꽂으면 GP11 의 전압은 얼마가 되고, 초음파 센서는 어떻게 되는지 쓰시오.[6점]

5 × 1/3 ≈ 1.67V → 2V 보다 낮아 HIGH 로 읽지 못해 거리를 재지 못한다(응답 없음).

(3)ECHO 를 GP11 에 바로 잇지 않고 저항으로 나누는 까닭을 쓰시오.[6점]

Pico 입력 핀은 최대 3.3V 라서 5V 를 그대로 넣으면 망가질 수 있기 때문.
채점 기준
  • (1) 식 4점 + 답 3.3V(3.33V) 4점. 식 없이 답만 쓰면 4점.
  • (2) 1.67V 2점 + HIGH 로 못 읽음 / 측정 실패 4점.
  • (3) Pico 입력 최대 3.3V 4점 + 5V 면 손상 2점.

5포토커플러 + 릴레이로 모터 켜기

20점 · 약 10분

추가 회로에서 포토커플러 모듈의 IN1 = 5V, IN1 옆 G = GP13 이고, 릴레이는 COM = 5V, NO → 모터 입니다. 그래서 GP13 이 LOW(0V) 일 때 모터가 돕니다.

(1)GP13 이 LOW 가 되었을 때 모터가 돌기까지의 과정을 아래 낱말을 모두 써서 순서대로 서술하시오.[12점]

낱말: 적외선 LED · 포토트랜지스터 · 릴레이 코일(전자석) · COM · NO
GP13 이 0V 가 되면 LED 양끝 전압 차가 5V 가 되어 칩 안 적외선 LED 가 켜진다 → 빛을 받은 포토트랜지스터가 켜져 릴레이 Signal 이 HIGH 가 된다 → 릴레이 코일에 전류가 흘러 전자석이 되고 가동편을 당긴다 → COM 이 NO 에 붙어 5V 가 모터로 가서 모터가 돈다.

(2)릴레이 코일(5V · 약 70mA)을 Pico 핀으로 직접 켜지 않는 까닭을 쓰시오.[4점]

Pico 핀은 수 mA 밖에 내보내지 못해서 — 모듈의 트랜지스터가 대신 코일 전류를 흘린다.

(3)포토커플러를 쓰면 좋은 점을 「빛」 과 관련지어 쓰시오.[4점]

입력과 출력 사이에 전선이 없고 빛으로만 신호가 건너가서(절연), 모터 쪽 전기 잡음 · 높은 전압이 Pico 로 들어오지 않는다.
채점 기준
  • (1) LED 켜짐(전압 차 5V) 3점 · 포토트랜지스터 켜짐 3점 · 코일 전자석 3점 · COM–NO 연결 → 모터 3점. 순서가 틀리면 해당 단계 0점.
  • (2) 핀 전류 부족 4점. (3) 빛으로 전달 · 절연(Pico 보호) 4점.

6PWM 으로 LED 밝기 조절

15점 · 약 8분

밝기 LED 는 GP22 에서 1000Hz PWM 으로 켭니다(한 주기 = 1ms). 코드는 duty cycle 을 0 ~ 100% 로 바꾸며 밝기를 조절합니다.

(1)PWM 이 무엇인지 「켜고 끄기」 라는 말을 넣어 설명하고, duty cycle 의 뜻을 쓰시오. 또 LED 의 duty cycle 을 25% → 75% 로 바꾸면 LED 밝기가 어떻게 되는지 까닭과 함께 쓰시오.[9점]

PWM 은 핀을 아주 빠르게 켜고 끄기를 되풀이하면서, 켜져 있는 시간의 비율로 평균 전압(밝기)을 조절하는 방법이다. duty cycle 은 한 주기 가운데 켜져(HIGH) 있는 시간의 비율(%)이다. 25% → 75% 로 바꾸면 켜진 시간이 길어져 평균 전압이 커지므로(약 0.83V → 2.48V) LED 가 더 밝아진다.

(2)같은 duty 50% 라도 2Hz 에서는 LED 가 깜빡이고 1000Hz 에서는 은은하게 보이는 까닭을 쓰시오.[6점]

1000Hz 는 1초에 1000번 켜고 꺼서 눈이 따라가지 못해(잔상) 켜진 시간의 평균만큼의 밝기로 보인다. 2Hz 는 느려서 켜짐 · 꺼짐이 눈에 보인다.
채점 기준
  • (1) PWM 뜻(빠르게 켜고 끄기 · 켜진 시간 비율로 조절) 3점 + duty cycle 뜻(한 주기 중 켜진 시간 비율) 3점 + 75% 가 더 밝음과 까닭(평균 전압 증가) 3점.
  • (2) 빠르게 켜고 끔 / 눈이 따라가지 못함(잔상) 3점 + 평균 밝기로 보임 3점.
