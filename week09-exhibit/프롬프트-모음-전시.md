## 2-1 · 전시 모드 — **코드는 선생님이 줍니다** (20분)

> 🎯 **왜 이것만 코드를 나눠 주나.**
> 센서와 액추에이터는 팀마다 다르지만, **Wake Lock 은 모든 팀이 똑같습니다.**
> 팀마다 다를 이유가 **하나도 없는 코드**를 매번 AI 가 새로 쓰면, 매번 다르게 틀립니다.
> 그리고 **9주차가 마지막 수업이라 전시 모드가 깨지면 되돌릴 기회가 없습니다.**
> 아래 블록은 Chromium 으로 **19가지를 실측해 통과한 것**입니다.

**붙여넣을 블록** — `week09-exhibit/page_exhibit_reference.tsx` 의 `★ 9주차` 두 덩어리

```tsx
// ★ 9주차 — 전시 모드: 화면이 꺼지지 않게 막습니다
useEffect(() => {
  if (!kiosk) return;
  let lock: { release: () => Promise<void> } | null = null;

  const acquire = async () => {
    try {
      const nav = navigator as Navigator & {
        wakeLock?: { request: (t: "screen") => Promise<{ release: () => Promise<void> }> };
      };
      if (nav.wakeLock) lock = await nav.wakeLock.request("screen");
    } catch { /* 지원하지 않는 브라우저에서도 멈추지 않습니다 */ }
  };
  // 다른 탭에 갔다 오면 잠금이 풀리므로 다시 겁니다
  const onVisible = () => { if (document.visibilityState === "visible") acquire(); };

  acquire();
  document.addEventListener("visibilitychange", onVisible);
  return () => {
    document.removeEventListener("visibilitychange", onVisible);
    lock?.release().catch(() => {});
  };
}, [kiosk]);

// ★ 9주차 — ESC 로 전체화면을 빠져나와도 전시 모드가 같이 꺼지게
//   이게 없으면 버튼이 숨겨진 채로 남아 되돌릴 방법이 없어집니다.
useEffect(() => {
  const onFsChange = () => { if (!document.fullscreenElement) setKiosk(false); };
  document.addEventListener("fullscreenchange", onFsChange);
  return () => document.removeEventListener("fullscreenchange", onFsChange);
}, []);

const toggleKiosk = async () => {
  const next = !kiosk;
  setKiosk(next);
  try {
    if (next) await document.documentElement.requestFullscreen();
    else if (document.fullscreenElement) await document.exitFullscreen();
  } catch { /* 전체화면이 막혀도 전시 모드 자체는 동작합니다 */ }
};
```
